================================

الملفات:
--------
index.html          الرئيسية
products.html       المنتجات (يتطلب تسجيل دخول)
cart.html           السلة + خيارات الدفع (شامل Apple Pay)
account.html        حسابي
seller.html         لوحة البائع (رفع منتجات بصور)
admin.html          لوحة الإدارة (حذف / حظر / إدارة الطلبات)
terms.html          الشروط والأحكام
style.css / app.js / admin.js / firebase-config.js / firestore.rules

كيف تخلي نفسك أدمن؟
-------------------
1. سجل دخول في الموقع بحساب Google
2. ادخل Firebase Console → Firestore
3. افتح مجموعة customers
4. اضغط على مستند الـ UID حقك
5. أضف حقل جديد:
   - Field: role
   - Type: string
   - Value: admin
6. احفظ
7. ارجع للموقع وافتح admin.html

صلاحيات الأدمن:
---------------
- حذف أي منتج
- إخفاء منتج
- حظر / إلغاء حظر عميل
- تغيير حالة الطلبات (قبول / رفض / مكتمل...)
- مشاهدة الإحصائيات

ملاحظات:
---------
- لازم تفعّل Authentication → Google
- لازم تنشئ Firestore وتطبق القواعد من firestore.rules
- لازم تفعّل Storage وتطبق قواعد الصور
- المنتجات تظهر فقط بعد تسجيل الدخول
- لا توجد منتجات تجريبية
